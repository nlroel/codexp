<p align="center">

</p>

## What is Codexp?

Codexp is a fork of [OpenAI's Codex CLI](https://github.com/openai/codex) that gives you control over what environment information is sent to the model server. It replaces automatically-collected local data (timezone, system language, device fingerprint) with configurable virtual values.

**Key differences from Codex CLI:**

| | Codex | Codexp |
|---|---|---|
| Binary name | `codex` | `codexp` |
| Config directory | `~/.codex` | `~/.codexp` |
| Env variable | `CODEX_HOME` | `CODEXP_HOME` |
| Timezone sent | Your real timezone | `America/New_York` (configurable) |
| Locale sent to shells | Your system locale | `en_US.UTF-8` (configurable) |
| Device fingerprint | Persistent UUID | Passkey-derived UUID (configurable) |
| Coexists with Codex | — | Yes, fully isolated |

## Quickstart

### Installing Codexp CLI

Run the following on Mac or Linux:

```shell
curl -fsSL https://raw.githubusercontent.com/nlroel/codexp/codexp-v0.154.0/scripts/install/install.sh | sh
```

Run the following on Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/nlroel/codexp/codexp-v0.154.0/scripts/install/install.ps1 | iex
```

Then simply run `codexp` to get started.

### First Run

On first run, Codexp automatically creates `~/.codexp/obfs.toml` with privacy defaults:

```toml
# Codex Privacy Obfuscation
# Auto-generated on first run. Edit values as needed.
enabled = true

[environment]
timezone = "America/New_York"

[shell_environment]
locale = "en_US.UTF-8"

[metadata]
installation_id_passkey = "<auto-generated-random-uuid>"
```

## Privacy Configuration

Edit `~/.codexp/obfs.toml` to customize what is sent to the server:

### `[environment]`

| Field | Default | Description |
|-------|---------|-------------|
| `timezone` | `America/New_York` | Replaces the IANA timezone string in `<environment_context>` |
| `current_date` | *(not set — real date passes through)* | Replaces the local date |

### `[shell_environment]`

| Field | Default | Description |
|-------|---------|-------------|
| `locale` | `en_US.UTF-8` | Replaces `LANG`/`LC_ALL`/`LC_CTYPE` for child shell processes. Forces English output. |

### `[metadata]`

| Field | Default | Description |
|-------|---------|-------------|
| `installation_id_passkey` | *(auto-generated)* | SHA-256 hash of this value produces a stable UUID v4. Same value = same UUID. Change it to get a new identity. |

### Global

| Field | Default | Description |
|-------|---------|-------------|
| `enabled` | `true` | Set to `false` to pass all real values through |

## What is NOT obfuscated?

Codexp does **not** fake the following, because the model needs them to work correctly:

- **Working directory (`<cwd>`)** — the model uses real paths to read/write files
- **Filesystem sandbox config** — the model needs to know what it can access
- **Shell type (`<shell>`)** — the model needs to generate correct commands
- **Network domain config** — user-configured, not auto-collected
- **User-Agent (OS/arch)** — standard HTTP practice, low privacy value
- **Git status/changes** — the model needs this for development work

## Coexisting with Codex

Codexp is fully isolated from the official Codex CLI:

- Different binary name (`codexp` vs `codex`)
- Different config directory (`~/.codexp` vs `~/.codex`)
- Different environment variable (`CODEXP_HOME` vs `CODEX_HOME`)
- Different installation_id

You can have both installed simultaneously without any conflict.

## Building from Source

```shell
git clone https://github.com/nlroel/codexp.git
cd codexp/codex-rs
cargo build --release --bin codexp
```

The binary will be at `target/release/codexp`.
